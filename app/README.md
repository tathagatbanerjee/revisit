# Revisit local app

Run from the repository root with `docker compose up --build -d`, then open
http://localhost:4320 . For native startup here: `npm ci` then `npm start`.

Read the [runbook](../docs/runbooks/operations/local-app.md) for prerequisites,
imports, capture preparation and checks, and [current state](../docs/architecture/current-state.md)
for what is implemented versus unqualified. Paid cloud allocation is disabled.
