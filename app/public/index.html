02 / BRING A RECORDING

What does your video support?

STATIC RECIPE · PREPARATION

One continuous, steady shot.

Move around a mostly stationary, textured scene with overlapping views. Start with a landscape 16:9 recording. Avoid cuts, mirrors, motion blur and a camera that only rotates.

Choose up to 30 seconds. The initial recipe prepares 640 × 360 observations at 12 Hz. Static fitting does not preserve moving people.

Compute stays explicit.

Checking local setup…

Configure your own key

Set RUNPOD_API_KEY in the local server environment and restart. Docker Compose forwards it from your shell. The value never goes into browser storage or a run manifest.

Paid allocation is disabled in this preview. The historical worker code is available for review; independent deadline cleanup and a fresh-user reconstruction rehearsal are not yet qualified.

03 / THE EXPERIMENT RECORD

Useful results. Honest failures.

Static → short dynamic

SHARP and Brush established spatial inspection. Short MoSca fits demonstrated replay, with ghosted people and missing surfaces.

More views ≠ a complete person

Hybrids and calibrated refinement improved some images. Independently fitted actors still doubled, and shoe/hand support remained weak.

Get the world right first

Fixed cameras and observed background anchors improved long-span geometry. The tested static pipeline is the repeatable baseline.
