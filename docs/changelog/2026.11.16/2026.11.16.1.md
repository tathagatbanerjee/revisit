# Independent repository implementation and research migration

Implemented the local Revisit preview in the visible `opensource/revisit` checkout,
using the original experiment's app/docs/core-pipeline/ignored-working conventions.
It remains an independent Git repository with its own GitHub remote. Parent-local
exclusion prevents double-staging; Revisit's own ignore rules protect private data.

Added a localhost-only viewer, attributed/hash-verified community capture,
synthetic interaction diagnostic, static file and complete run import, timeline /
recorded cameras / navigation, local video upload and exact-PTS extraction,
explicit source review, CPU mapping and isolated worker handoff packaging. Added
server-environment read-only Runpod checks against RESTv2, fake-provider tests and
a disabled-by-default paid allocation route with an explicit unqualified status.

Migrated143 project-authored historical research/result records, the103-export
inventory and36 catalog entries without their media/checkpoints, cloud state or
credentials. Migrated selected project-owned native worker helpers/recipes with
source hashes; relocated workspace root, removed historical global budget code,
added public-source setup draft and preserved upstream notices. No native GPU run
or paid worker allocation was performed. Research/evaluation dependencies remain
separately licensed and the migrated GPU setup is not yet qualified.

Added Docker/native runbooks, capture/Runpod guides, artifact schema, dependency /
asset notices, credential-free CI, link/syntax checks and an intended-file/history
publication audit. Chromium verified real sample rendering, translation, synthetic
playback/time-camera independence and mobile layout. Node tests cover import,
security boundaries, interruption, provider semantics and actual video extraction.
The Docker build and credential-free doctor pass on Linux amd64. A Docker network
pool exhaustion needed a local ignored subnet override; unrelated services were
not pruned or modified. A30s reference extraction exposed FFmpeg5 expression/threading limits in the
container. Balanced selection expressions, bounded filter/output threads and
clearer diagnostics address that path; failed attempts are retained locally.

See docs/testing for actual verification records and remaining release gates.
Paid lifecycle/deadline and independent fresh-user qualification are incomplete;
no claim of completed upload-to-paid-reconstruction is made.

The final CPU reference replay passed all 360 frames/cameras, minimum 171 observed
anchors and isolated handoff generation in 160.323s. Five CPU contract tests and
the hash-checked pinned-source depth patch also pass. See testing receipts; the
reference media and 136MB handoff remain private local data.

Final browser testing also caught and fixed a stale sample-download selection
race and wrapping of long retained error messages on mobile. The final Docker
preview passes the real-sample/synthetic playback/mobile browser smoke.
