# Easier first use: browser viewer, walkthrough and cache controls

The README now leads with a browser-only Guildhall viewer and a real 30-second
walkthrough (source clip plus recorded full-density inspection states). Tour media
lives in GitHub Releases, with its own notice; no raster/media was added to Git.
The main sample, observations, point counts and original hashes are unchanged.

Both apps show cache usage, remaining download size and active progress, with
explicit full offline download, cancellation/resume and sample-only clearing.
Local clearing preserves uploads/imported runs. A complete set of existing expanded
models also qualifies as offline-ready without redownloading shared parts.

The hosted Worker exposes an allowlist of pinned public assets and read-only
metadata. It streams bytes rather than assembling models in its memory. Its
service worker verifies/reassembles original PLYs and caches shared parts and the
interface for offline reloads. It receives no recordings or credentials and cannot
allocate workers. Browser quotas/eviction and tab lifetime remain practical limits.

Setup checks cover Docker/Compose, disk, ports and browser graphics, with concrete
remedies. REVISIT_PORT avoids editing Compose for a busy host port. An independent
installation checklist and issue form accompany automated Windows/macOS/Linux
contracts/cache/build checks and a manually triggered fresh Linux Docker rehearsal.
Automated platform checks do not establish human/Desktop/browser qualification.

Verification includes Node contracts and cache isolation/integrity checks,
hosted model navigation and offline reload, source byte ranges, the walkthrough's
actual duration/hash, publication scanning, and the hosted Worker build. See
[hosted receipt](../../testing/hosted-smoke.json),
[tour receipt](../../testing/readme-tour.json), and
[rehearsal procedure](../../testing/fresh-install.md).
No GPU workers were created and no cloud keys were required.

Final recorded checks: all 22 Node tests, hosted offline reload, local community/
synthetic/mobile regression, and public deployment passed.
[Portable platform CI](../../testing/portable-platforms.json) passed on Linux,
Windows and macOS. [Clean Linux Docker rehearsal](../../testing/clean-linux-rehearsal.json)
passed on a fresh GitHub runner, with a 76s build and 1.38s public data verification.
No independent human/Desktop qualification is claimed.
