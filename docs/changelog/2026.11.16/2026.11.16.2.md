# Guildhall becomes the main research example

The landing page now presents our fixed-world Guildhall full-interior experiment:
source video first, then a button into the interactive reconstruction. Houseplant
moves into secondary samples. README and local startup instructions follow the
same journey, without Runpod credentials or a new training job.

All 305 original observations through 25.333 seconds and all 475,357 Gaussians per
state remain available. No point decimation, time resampling or new inference was
performed. Every state has the exact same 397,518-point static prefix. Splitting
that prefix from each state's motion bytes reduces public downloads from
9,859,031,060 model bytes to about 1.65 GB including source media, without changing
reconstructed PLY bytes. The downloader verifies both parts and each assembled
model against the original export hashes, deduplicates concurrent requests and
atomically caches results outside Git. Expanded cache can reach about 11.5 GB.

The first state needs about 31 MiB; further visited states need about 5 MiB each.
Playback waits for loading and can be slower than the recording. The app does not
prefetch the complete sequence. Source video is a silent 1280×720 excerpt from
original 50–75.433 seconds. The edited transition/outro remain excluded.

Code remains MIT. Acabashi's source and the derived sample retain CC BY-SA 4.0
attribution in the UI, notices and sample release. Media is stored in the
`guildhall-fixedworld-v1` GitHub release; credentials, checkpoints and worker state
are excluded. Other historical assets remain local. No paid workers were created.

Quality limitations remain explicit: ghosted people, turn blur, missing surfaces,
and failed original motion coverage on 87 frames. This is our full-interior
showcase, not a claim of held-out or novel-view accuracy.

Verification: 15 Node tests and syntax checks; documentation/link and publication
scans; Docker build; source MP4 range checks; browser first/middle/final density,
translation at fixed time, seeking at fixed viewpoint, recorded camera reset,
and existing community/synthetic/mobile regression. Receipts:
[Guildhall browser](../../testing/guildhall-smoke.json),
[existing browser checks](../../testing/browser-smoke.json).

A [clean public download](../../testing/guildhall-public-download.json) fetched
the source video and assembled the exact original first-state model in 7.2s on
this connection. Both browser scenarios pass in separate contexts; selecting the
secondary Houseplant sample now scrolls to the viewer as Guildhall does. The
software-rendered checks use a 160px inspection viewport without reducing points.
